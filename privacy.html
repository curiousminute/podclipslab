Pod Clips Lab Publisher: Privacy Policy

The tool signs in only the Pod Clips Lab account owner with TikTok Login Kit. It stores the TikTok access token on the owner's own computer in order to post videos, and it reads only the basic profile information that posting needs (nickname, avatar, posting limits). It collects no data from viewers or other users, and it shares, sells or uses no data for anything else. The owner can revoke access at any time in TikTok's settings, and the local token is then deleted.
